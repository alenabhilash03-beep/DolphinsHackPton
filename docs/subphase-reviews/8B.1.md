# 8B.1 review — Grounded synthesis schema and tool

## Delivered

- `ScientificSynthesis` contract on `AgentTurn.synthesis`: answer to the hypothesis with a verdict and stated basis, cited paper findings, disagreements, missing evidence, simulation implications bound to solver fields, limitations, next experiments and per-source access. Paper findings, conditional simulation predictions and hypotheses needing validation are distinct typed sections.
- `synthesize_grounded_answer` agent tool and `app/research/synthesis.py` service. Nemotron proposes qualitative statements from this turn's inspected passages and accepted result only; the server attaches citation metadata and solver values and validates every reference.
- The agent must attempt synthesis after interpretation, and before concluding research that inspected sources but produced no result. An unavailable or rejected synthesis never changes the turn status or numerical result.
- Execution ledger, generated OpenAPI/TypeScript contracts and the investigation panel's tool label include the new tool. The deterministic `Interpretation` is unchanged. Contract and behaviour are documented in `docs/GROUNDED_SYNTHESIS.md`.

## Verification

- **365 backend tests pass, 27 of them new.** 45 frontend tests, TypeScript, contract checks and the production build pass.
- One backend test fails and did so before this work: `test_saved_demo_matches_current_solver_and_public_asset`. On the verification machine the solver output differs from the saved demo arrays by at most 8.8e-9 relative. The documented prior count was 339 passing, so this looks machine-dependent; it was not investigated further.
- Required rejections are tested: nonexistent, altered and joined citations; unsupported numbers, including spelled-out quantities and numbers borrowed from another scenario; stale, foreign and textual-null result references; quantities altered after assembly.
- Required scenarios are tested: abstract-only access, contradictory evidence (model-reported and extraction conflicts), no-result research, and missing data or provider failure.
- Live, traced Nemotron edit ("Run this comparison for 120 days"): read → apply → simulate → interpret → synthesize, grounded `simulation_only` synthesis in 7.4 s, remote trace verified.
- Live Nemotron synthesizer through the agent tool on the synthetic test abstract: grounded for both the result case (6.6 s) and the no-result case (9.6 s). The agent loop in this check is the scripted harness.
- Live runs during development drove four validation additions, each now covered offline: spelled-out quantities, simulation facts filed under paper citations, quotes joined across sentences, and oversized or mis-shaped lists.

## Live real-paper run (added after the first review)

The user ran `scripts/run_generalized_agent.py --mode primary` locally with Europe PMC reachable. It completed in 99.9 s: two live abstracts retrieved, one extraction rejected (a clearance range, correctly not a scalar), one `no_values`, audited comparison simulated, and a grounded `research_and_simulation` synthesis in 6.9 s with two verbatim-cited, abstract-only paper findings. Tracing was local only. Two defects in that output were fixed and covered by tests:

- A limitation arrived as a serialized nested list inside one string and was shown as-is. Such statements are now rejected.
- The answer said `supported` for "maintain occupancy longer" although both alternatives stayed above threshold for the whole window, so duration was censored. That verdict is now rejected for duration questions; a live recheck on the same result returned `undetermined` with the censoring stated.

This closes the first "not verified" item below for abstract-only access. Full-text retrieval was not exercised in that run. Backend tests: 366 pass.

## Not verified

- **Live paper research feeding synthesis.** The cloud verification environment blocks Europe PMC (`www.ebi.ac.uk`), so the reviewed primary question stopped at an honest search-unavailable outcome with no synthesis. No real paper passage has been through the live synthesizer.
- **Live agent behaviour on the no-result research path.** The live generalized research run fails in that environment on an existing provider call that exceeds its 30-second proxy limit, with or without this change. The gating itself is covered by the scripted-agent tests and by the live edit run.
- **Semantic support.** Validation proves a quote exists in an inspected passage and that numbers come from a statement's own references. It does not prove the statement follows from the quote; the key-term check is only a coarse guard.

## Observations

- Yield is not guaranteed. In the recorded runs each accepted synthesis took one or two attempts; a proposal that fails twice is recorded as rejected with no model text.
- For edits the verdict is fixed to `undetermined`, because an edit instruction is not a hypothesis. One live edit answer described the lack of literature rather than the result; the implications carried the findings.
- Synthesis adds one provider call (about 6–13 s observed) to every completed turn and to no-result research that inspected sources.

## Plan assessment

**Keep the plan.** No scope or sequence change is needed. The two open verification items are environment limits, not design findings; both should be rerun where Europe PMC is reachable (`scripts/run_generalized_agent.py --mode primary --require-tracing`) before the synthesis is relied on in a demo.
