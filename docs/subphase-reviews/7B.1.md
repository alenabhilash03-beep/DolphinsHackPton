## Boundaries

`ResearchPreparation` always has `runnable:false` and `configuration_required:true`; its readiness state is `ready_for_configuration`. Readiness records describe checks but do not prove the checks ran. Source-passage verification, canonical hash computation, persistence/concurrency enforcement and actual applicability/configuration validation are future service responsibilities. Existing `ExperimentConfig` and its candidate-evidence safeguards remain unchanged. A complete synthetic record is not an evidence-backed new drug demonstration. Existing assessment and simulation endpoints retain their contracts; there is no new preparation execution endpoint yet.

The agent will perform research/extraction/configuration via real tools and explain solver results. This chunk defines those data boundaries; it does not implement or replace that future agent workflow with a manual pipeline.
