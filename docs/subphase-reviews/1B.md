# Subphase 1B review — binding and comparison metrics

## Delivered

- `apps/api/app/simulation/binding.py` implements the effective 1:1 mass-action right-hand side and linked kinetic edits. Affinity changes hold association fixed and derive dissociation; direct rate edits derive model KD. The module does not equate KD-only evidence with known kinetic rates.
- `apps/api/app/simulation/solver.py` drives target occupancy from the exact 1A central concentration and the explicit exposure factor. SciPy Radau integrates each administration interval separately with `rtol=1e-6`, `atol=1e-9` by default and a dense solution. Binding occupancy stays continuous across a hypothetical bolus; central concentration can jump. Solver failures, nonfinite outputs, and material occupancy range violations fail rather than yielding plausible-looking curves.
- `apps/api/app/simulation/metrics.py` calculates central concentration AUC from the exact PK segments and occupancy AUC in the adaptive solve, independently of display sampling. It locates occupancy threshold crossings from the dense solution and reports every above-threshold interval, total duration, first upward crossing, first subsequent downward crossing, and an explicit horizon-censoring status.
- `apps/api/app/simulation/comparison.py` runs every validated scenario over one shared horizon and threshold, preserving the configured scenario order. It returns trajectories plus `ScenarioMetrics` without invoking an LLM or a web service.
- `ThresholdOutcome` now carries `above_threshold_intervals_h` in the Python contract, OpenAPI schema, and generated TypeScript types. This was already specified in the model document and is needed for repeated dosing.
- NumPy and SciPy were added to the Python lockfile.

The primary results remain conditional on the reduced PK, transferred binding kinetics, prescribed exposure factor, fixed independent effective sites, and other assumptions in `docs/model.md`. The 90% threshold is an analytical choice, **not** a therapeutic threshold. Endpoint saturation and censoring preclude a justified "winner" when both alternatives remain above threshold at the horizon.
