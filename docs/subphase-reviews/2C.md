# Subphase 2C review — live update reliability

## Delivered

- A headless `WorkspaceController` now owns simulation requests independently of React and the UI layout. A 150 ms debounce coalesces rapid edits to the same field. Different fields queue in order; the workspace publishes only the final settled result, so an older response cannot overwrite newer changes. Reset cancels pending work and ignores late responses.
- The React hook exposes `pendingEdits`, `busy`, errors, and measured API and edit-to-result durations. A failed edit keeps the last valid comparison visible. Parameter edits call the deterministic `/api/simulations/adjust` route directly, with no LLM path.
- Logarithmic mappings and a functional native control panel cover dose, effective half-life, association/dissociation, model KD, dosing interval, common duration, and analytical threshold. The UI contributor can replace the panel's plain presentation while keeping the controller and typed API. The baseline remains protected; linked scientific values and custom-mode provenance come from FastAPI.
- `/preview/plots` now provides an end-to-end technical workspace: editable alternatives, three scenario curves on each of two plots, shared play/pause/scrub timeline, synchronized readouts, loading/error feedback, and live request timing.
