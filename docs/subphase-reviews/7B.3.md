## Boundaries and findings

Preparation readiness is metadata, not run authorization. Only the configuration service issues a receipt; the solver checks the exact configuration hash. Pure PK/binding equations remain independent of LangChain. Control changes use the existing deterministic path with parent receipt lineage and no LLM call.

The service currently configures one structured baseline and returns `hypothesis_parsed:false`. It does not silently interpret natural-language interventions. Full agent-owned research and experimental editing are 7C; the workspace flow is 7D. Source/context matching cannot establish complete biological applicability, source truth, construct identity or expert review; output remains conditional and source evidence stays candidate. No explicit competition, oral absorption, equilibrium-only or downstream efficacy model was added.

Integration checks found and fixed the remaining custom-only bolus opt-in in the numerical wrapper, source-page version continuity during cache replay, and input/context provenance checks. These are routine correctness fixes within the agreed scope.
