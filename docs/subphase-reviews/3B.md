# Subphase 3B review — guarded single research agent

## Delivered

- A single LangChain `create_agent` uses three actual tools: read the audited trastuzumab profile with parameter units/locators, verify exact S2/S3 Europe PMC literature identities, and run the deterministic SciPy three-scenario comparison. The agent returns a Pydantic `ToolStrategy` response. The orchestration interface returns a complete validated experiment, result, result-linked interpretation, retrieval status, and trace metadata for Phase 3C.
- A deterministic preflight gate rejects unregistered drugs, other targets/routes, unsupported clinical endpoints, parameter overrides, and interventions outside the audited primary comparison. Postflight checks require all tool calls, source identity, cited evidence IDs, exact experiment/result IDs, and local trace spans. Wrong source identity is rejected; a genuine provider outage uses the labeled bibliographic cache without promoting it to new scientific evidence.
- All numerical interpretation claims come from solver metrics. Both alternatives remain above the 90% analytical threshold at the 180-day horizon; the time-to-loss comparison is censored. The agent can select only allowlisted follow-up experiments. Slider edits remain direct simulator calls and do not invoke the LLM.
- `scripts/run_research_agent.py --live` invokes only the pinned NVIDIA Nemotron endpoint. Optional `--require-tracing` reads back the remote LangSmith root and checks retrieval/simulation spans when credentials are configured. No paid OpenAI fallback is present.
