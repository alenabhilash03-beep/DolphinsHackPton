# Subphase 4C — scientific review and core acceptance

The essential scientific MVP passes the core acceptance gate on 2026-11-14. Predictions remain conditional model outputs; no clinical or measured tissue-occupancy validation is claimed.

## Audit and fixes

| Area | Evidence / outcome |
| --- | --- |
| Units | Canonical hour, nmol, nM and liter conversions tested; M⁻¹s⁻¹ → nM⁻¹h⁻¹ and s⁻¹ → h⁻¹ retained |
| PK and dosing | Analytical one-compartment propagation, partial/repeated infusions, explicit hypothetical bolus, linked clearance/half-life and computational limits tested |
| Binding | Mass action, fixed nondepleting sites, occupancy bounds, zero exposure, analytical reference and tighter-tolerance convergence tested |
| Preset fairness | Dose, association and other held parameters remain fixed for the registered three-scenario comparison; KD = koff/kon remains consistent |
| Thresholds | Dense-solution crossings and multiple dosing intervals are independent of plotting density; horizon censoring is explicit |
| Molecular forms | Intact-IgG rate provenance is distinct from the cached Fab–HER2 geometry; 1N8Z labels identify the experimental fragments |
| Scientific support | Fixed a bypass: a caller can no longer relabel or numerically modify a reviewed preset and preserve its reviewed status. All scientific content must match the audited registry; custom runs receive an explicit unvalidated-input warning |
| Research scope | Added a conservative vocabulary gate so additional drug/target/numerical instructions cannot be silently omitted from the fixed primary experiment |
| UI/result linkage | Current solver metrics update after edits; old agent interpretation is hidden; geometry is independent of PK and binding changes |

## Acceptance checks

- 86 Python tests passed, including nine new support-boundary cases.
- 19 frontend tests and shared contract validation passed. The unchanged frontend had passed its production build during 4B.
- The primary live NVIDIA workflow passed after the tightened checks, including remote LangSmith readback. The result remains the reviewed primary comparison; scientific numeric inputs did not change.
- The integrated structure/research/plot/control walkthrough was verified in 4B.

No critical scientific mismatch remains within the declared reduced-model scope. Custom values are hypothetical and do not acquire drug-specific validation merely by running the solver. The text gate intentionally rejects unsupported phrasing instead of silently accepting additional interventions.

**Plan assessment: keep the plan.** These are acceptance fixes within the existing scope. Phase 4 is complete. Later resilience and demo phases retain their separate acceptance gates, including deployment verification.
