## Findings and limitations

The real source uses a standard external JATS document declaration. An initial parser restriction incorrectly forced abstract fallback. The reader now accepts inert external declarations while rejecting internal subsets/entity definitions, with regression coverage. Bounded pages and stable locators allow the agent to inspect later results instead of silently treating a partial snapshot as the full article. Each page gets its own source ID/hash for later evidence references. These were routine implementation fixes, not scope changes.

Exact source matching proves a proposed number/quote is present; it cannot establish correct biological meaning, construct match or model applicability. Instruction-pattern detection is a heuristic, not a universal prompt-injection defense. Unknown context, incompatible units, unsupported notation, missing values, inaccessible tables/images and partial documents can still prevent useful extraction. No OCR, arbitrary browsing, new model equations, downstream efficacy model or automatic promotion to reviewed evidence was added. Search/extraction sessions must remain isolated per preparation. Outer-agent trace/deadline enforcement and source-content-as-data rules remain 7C responsibilities.

There is no new UI workflow or preparation execution endpoint. The current primary research agent is unchanged; these tools will be connected to its generalized successor in 7C. The existing scientific execution/provenance gates remain intact.
