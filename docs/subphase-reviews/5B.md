# Subphase 5B — failure recovery and local deployment preparation

Completed 2026-11-14 for the user's selected local-demo deployment.

## Delivered

- Research now runs in supervised child processes. A 180-second configurable submission deadline includes queue wait; workers are terminated on timeout or shutdown. A worker watchdog also exits after supervisor loss. Two supervisors handle at most four accepted jobs by default; saturation returns 429 with `Retry-After`. Late output cannot change terminal state. Scientific simulation routes remain independent of that queue.
- SQLite migration adds process ownership. Recovery marks jobs interrupted only when the owner has died; importing the app for contracts or tests no longer cancels a live server's jobs. Browser reload reconnects to the last submitted job when local storage is available. Failed jobs expose a retry action.
- A typed, versioned saved result is available from `/api/demo` and as a local frontend asset. The UI can load it while FastAPI is down, with an explicit saved/cached/no-live-research banner. Its plots, structure, schematic, and timeline remain interactive. Parameter edits need FastAPI; failed edits retain the prior valid result. The snapshot is generated by the current numerical engine without AI or network access and is linked to its interpretation and reviewed configuration.
- Structure/evidence asset errors have retry actions; visualization error boundaries preserve the rest of the workspace after renderer or chunk failures. Existing literature outages still use the labeled audited cache without inventing new measurements.
- `scripts/start_local.py` launches and checks local services, supports alternate ports and intentionally disabled AI, writes ignored logs, and stops both process groups. Its smoke mode verifies clean startup, saved assets, direct simulation, and offline failure paths before exiting. `docs/LOCAL_DEPLOYMENT.md` provides local operation and future hosting preparation. Public deployment remains outside the agreed local-demo gate.
