# Subphase 3C review — research jobs and workspace flow

## Delivered

- SQLite-backed research jobs with queued, running, completed, unsupported, and failed states. A worker runs the guarded 3B agent on the pinned NVIDIA model. Successful tool completions emit factual progress records. The API exposes submit, status, and replayable SSE routes; `Last-Event-ID` resumes missed events. Jobs interrupted by an API restart become explicit failures rather than remaining indefinitely running.
- The Next.js same-origin proxy forwards those routes without sending credentials to the browser. `HypothesisWorkspace` supplies natural-language and optional drug, target, route, dose, and duration fields, displays activity and scope reasons, and loads the validated experiment, numerical result, and linked interpretation. Unsupported hypotheses and provider failures leave direct simulation usable.
- The existing headless workspace accepts a completed research result without another LLM or solver call. Slider edits continue through `/api/simulations/adjust`. Agent claims are hidden when a control edit creates a different result ID. The stale “configuration fixture only” label is omitted from post-simulation interpretation and evidence displays; the checked-in configuration fixture and its original hash remain unchanged.
- Shared OpenAPI and TypeScript contracts now expose the research job and SSE event shapes. The UI contributor can replace the plain preview styling while preserving the typed data path.
