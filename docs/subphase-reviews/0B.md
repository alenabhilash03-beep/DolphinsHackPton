## Provider decision and limits

The user specified a zero budget for paid API calls and selected NVIDIA Nemotron 3.5 Super VL for testing. The audited prototype endpoint is `nvidia/nemotron-3.5-super-vl-120b-a12b`, accessed through the NVIDIA LangChain adapter. No paid OpenAI request or local model download was used.

Use LangChain's **ToolStrategy** for the agent's final structured response, with deterministic checks that required tools ran and their results were preserved. The native-format diagnostic's missing tool execution is a concrete reason not to select that path. An independently schema-valid response does not prove evidence retrieval or tool use.

Free endpoint access and limits can change. The probe pins the audited model, requires an explicit `--live`, and does not silently fall back to a paid provider. Runtime source retrieval, full hypothesis parsing, model selection, and result-linked interpretation still require the Phase 3 evaluations. LangSmith account configuration and a verified trace must be completed before the sponsored-track integration is considered done.
