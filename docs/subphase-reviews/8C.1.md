# 8C.1 review — Verified structure-analysis tools

## Delivered

- **Service** (`app/structures/`): hash-verified loading of the 1N8Z and 1IEP coordinate files, deposition metadata with species and construct, interface contacts within 4 Å, and residue distances against a named or the nearest binding-partner residues.
- **Three LangChain tools:** `find_verified_structure`, `list_interface_contacts`, `measure_residue_distance`, plus three read-only API routes under `/api/structures`.
- **Provenance on every result:** PDB ID, coordinate SHA-256, source URL, cutoff rule, structure scope and the limits of what a distance means.
- **Explicit unavailable outcomes** for unknown pairs, altered or missing assets, unresolved or absent residues, non-partner atoms, same-partner pairs and pairs in different crystal copies.
- **Viewer parity** proven through a fixture generated by the viewer's own geometry code and checked by both test suites.

## Verification

- **378 backend tests pass (12 new) and 52 frontend tests pass (1 new).** TypeScript, contract check and production build pass. The one failing backend test is the same pre-existing saved-demo float mismatch.
- **Reference distances reproduced:** 1N8Z GLY B:103 O / LYS C:593 NZ at 2.416987174 Å with 32 interface pairs; 1IEP STI A:201 N51 / ILE A:360 O at 2.668499578 Å with 45.
- **Parity:** all 77 interface pairs and the sidebar neighbour lists have identical residue and atom identities and order in both implementations; distances agree within 1e-9 Å.
- **Required cases tested:** alternate conformers fail closed, REMARK 465 residues are reported unresolved, absent residues have no invented cause, same-copy and same-entity restrictions hold, altered assets are refused, results cannot mutate the cached model, unknown pairs return unavailable.
- **Live Nemotron:** with only these tools, the model found 1N8Z, listed contacts and measured the closest pair, with the tool returning 2.4169871741488387 Å; for cetuximab/EGFR it called the finder once and stopped on the unavailable result.

## Observations

- The Python geometry is an independent implementation, not shared code. The parity fixture must be regenerated whenever either side changes; both suites fail if it is stale.
- Metadata comes from the PDB header records. For the Fab chains the deposited organism field reads "MUS MUSCULUS, HOMO SAPIENS" (a humanized antibody); it is reported as deposited, not interpreted.
- A ligand such as imatinib has more than twenty protein residues within 4 Å, so a neighbour list of twenty can be entirely within the cutoff.
