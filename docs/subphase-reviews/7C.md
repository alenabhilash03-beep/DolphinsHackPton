## Boundaries and plan assessment

**Keep the implementation sequence.** No new model equations, additional reviewed drug profile or universal language parser is claimed. Initial generic research configures an explicitly authorized structured baseline; unrecognized interventions require clarification rather than silently substituting one. Accepted experimental edit grammar is documented and rejects unconsumed instructions. Existing primary jobs/UI remain compatible; generalized API integration, clarification UI and progress presentation are 7D.

The numerical interpretation is assembled by a tool from actual solver values, not free-form LLM numerical prose. Offline synthetic end-to-end success and live real-drug missing-data research are separate evidence. Deadlines are checked between calls; an in-flight provider call is bounded by its own timeout. API failures do not promise successful completion and persisted preparations can be read before retrying.
