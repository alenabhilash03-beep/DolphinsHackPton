# Subphase 3A review — evidence registry and Europe PMC retrieval

## Delivered

- `data/drugs/trastuzumab.json` is the runtime audited profile for intact trastuzumab–HER2. It carries the validated conditional experiment, exact S2/S3 PubMed/PMCID/DOI checks, and a 1N8Z reference explicitly scoped to Fab bound to HER2 extracellular domain. The older 0B example remains a contract fixture.
- `app.research.registry` validates the full experiment's existing provenance plus the exact identity, locators, reviewed status, and intact-antibody context of the selected PK and binding evidence. Two checked-in Europe PMC records cache bibliographic metadata and availability only. `scripts/refresh_literature_cache.py` rechecks exact identities before optional cache replacement; it never alters reviewed numerical inputs.
- `app.research.europe_pmc` provides a bounded core-result search and exact-PMID lookup with explicit missing abstract/full-text status and a provider error. `GET /api/research/search` exposes live candidate literature; `GET /api/research/evidence/trastuzumab` serves the audited profile with labeled cached bibliography. The generated OpenAPI and frontend types now include both response schemas.
- A same-origin Next.js evidence proxy and plain `EvidencePanel` display sources, the selected scenario's validated numerical provenance, limitations, and cached retrieval status in `/preview/plots`. User-edited parameters remain visibly unreviewed. The visual UI contributor can restyle or replace the panel.
